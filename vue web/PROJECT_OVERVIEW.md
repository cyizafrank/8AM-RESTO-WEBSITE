## 🎨 CUSTOMIZATION EXAMPLES

### **Change Primary Color**
Find `#ff6b35` and replace with your color:
```css
.hero { background: #yourcolor; }
.btn-primary { background: #yourcolor; }
```

### **Add New Menu Item**
In `Menu.vue`, add to menuItems array:
```js
{
  id: 37,
  category: 'Breakfast',
  name: 'Your Dish',
  price: 15.99,
  description: 'Your description',
  tags: ['Tag1', 'Tag2']
}
```

### **Add New Gallery Image**
In `Gallery.vue`, add to galleryImages array:
```js
{
  id: 18,
  title: 'Image Title',
  description: 'Image description',
  url: 'your-image-url.jpg',
  category: 'Food'
}
```
